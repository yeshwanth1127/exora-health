# Avocado Health — Modern Hospital Webpage

Design research for the proposed healthcare AI company website: [Healthcare AI website references](HEALTHCARE_AI_WEBSITE_REFERENCES.md).

A modern, high-conversion healthcare webpage for **Avocado Health**, built with React 19, Vite, Tailwind CSS, and Framer Motion / GSAP.

---

## Features

1. **Hero & Interactive Quick Booking Bar**:
   - Dynamic search by clinical specialty, Bengaluru clinic location, preferred date, and patient type.
   - Glassmorphism navigation with emergency standby hotline (`080 4968 2800`).
2. **Indian Healthcare Accreditations**:
   - Official logos for NABH, NABL, QCI, ICMR, and AHPI.
3. **Why Choose Us?**:
   - In-Person Care and Virtual Consultation dual cards with custom vector line art.
   - Core clinical stats: 25,000+ patients treated, 98.4% satisfaction, 92% early risk interception.
4. **Clinical Services Bento & Department Grid**:
   - Bento-box view and diverse department browser across Cardiology, Orthopedics, Neurology, Primary Care, and Dermatology.
5. **Top Specialists & Doctor Directory**:
   - Direct appointment scheduling with leading physicians and surgeons.
6. **Bangalore Clinic Locations**:
   - Interactive clinic map and consultation booking across Indiranagar, Koramangala, and Whitefield.
7. **Patient Stories & Clinical Testimonials**:
   - Toggleable patient experiences with audio waveform previews and verified stories.
8. **Insurance Partners & Direct TPA Desk**:
   - In-network cashless health insurance providers (Star Health, HDFC ERGO, ICICI Lombard, Care Health, Niva Bupa, SBI).
9. **Personalized Health Packages & Pricing**:
   - Static 3-tier health plans with annual and monthly billing toggle, featured recommended tier, and transparent inclusions.
10. **Doctor Drafts & Clinical Reports**:
    - Evidence-based health articles published by senior staff physicians.
11. **WhatsApp Floating Hub & Appointment Booking Modal**:
    - One-tap WhatsApp triage, direct reception call, and multi-step appointment booking.

---

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 6
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion & GSAP

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

Open `http://localhost:5173` to view the application in your browser.

### Production Build

```bash
npm run build
npm run preview
```
