Local speech, flexible intelligence

The dashboard, Whisper, Kokoro, and SQLite hospital knowledge store run on this machine. Conversation can use a local Ollama model or OpenRouter. Speech never leaves this Mac.

Model downloads need internet once. Transcripts are saved; microphone recordings are not. OpenRouter keys stay in the process environment.

What this hospital demo supports

Natural patient-access conversations, document-grounded hospital information, live doctor and availability lookup, and confirmed appointment booking through the hospital backend.

Clinical advice, diagnosis, medical-record access, ambulance dispatch, payment, and live transfer remain intentionally unavailable.
